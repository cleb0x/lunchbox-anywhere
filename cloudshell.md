# Lunchbox

Lunchbox puts Claude Code and your other AI agents in one room. Here it runs in your own free
Cloud Shell, with your own Claude subscription. Nobody else can open it.

## Start Lunchbox

Click in the terminal below, type this and press **Enter**:

```bash
./lunchbox
```

From now on this guide changes to show what to do next: signing in to Claude the first time, then a
button that opens Lunchbox.

## Next time

You don't need to type anything again. Open the Lunchbox website; if it says Lunchbox isn't running,
click **Start in Cloud Shell**. Lunchbox starts here by itself and the guide opens next to the
terminal with the button.
